# DndCompanion

DndCompanion is an Expo/React Native mobile app for quickly browsing Dungeons & Dragons 5th Edition reference data.

## Features

- Browse and search monsters, including detailed stats and images
- Browse and search spells, including casting details and descriptions
- Browse weapons and armor with equipment details

## Built with

- Expo and React Native
- React Navigation
- Expo SQLite
- The D&D 5e API
- TypeScript

## Getting started

Requirements: Node.js and npm.

```bash
npm install
npm start
```

Use the Expo CLI prompts to open the app in a simulator, emulator, or Expo Go.

Platform-specific start commands:

```bash
npm run android
npm run ios
npm run web
```
